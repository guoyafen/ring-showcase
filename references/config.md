# 素材配置

配置为 UTF-8 JSON。最小示例见 `../assets/config.example.json`；将示例图片路径改成真实文件，缺少高清图时删除 `hd`。相对图片路径基于 JSON 所在目录解析，也支持本地绝对路径。生成时图片复制到输出内，不会依赖原电脑路径。

## 页面与布局

| 字段 | 含义 / 默认 |
|---|---|
| `pageTitle`, `brand`, `brandMark`, `subtitle` | 浏览器标题、品牌、上标、中文副标题 |
| `season`, `receiptSeason` | 侧边系列名、小票系列名 |
| `statusTime`, `statusText`, `battery` | 装饰性状态栏，不读取系统状态 |
| `thanks`, `shopLabel`, `bagLabel` | 小票结尾、打开详情文字、加购计数名称 |
| `addFitLabel`, `addedFitLabel` | 整套加购前后的按钮文字 |
| `currency` | 价格前缀，默认 `¥`；金额不做汇率转换 |
| `discountRate` | 整套折扣减免比例，默认 `0.15`；`0` 为不减免 |
| `imageAspect` | 所有展示图的宽 / 高，默认 `0.6666666667`；热区以整图计算 |
| `gridColumns` | 1–4 列，默认 3；行数随数量计算 |
| `demoFeatureIndex` | D 演示突出展示的数组下标，默认 0 |
| `theme` | `background`、`ink`、`muted` 三个 `#RRGGBB` 色值 |
| `looks` | 1–12 项素材，排列顺序即环形/网格顺序 |

主题仅控制主背景、文字和线条，纸张/阴影/红色折扣保持原设计。需要大幅换肤时另外检查 CSS。

## 每个 look

```json
{
  "id": "01",
  "en": "SOFT DAY",
  "cn": "松弛通勤",
  "tag": "把今天穿得舒服一点",
  "img": "images/01.png",
  "hd": "images/hd/01.jpg",
  "hidden": false,
  "items": [
    {"name": "羊毛外套", "short": "外套", "cat": "OUTERWEAR", "price": 599}
  ],
  "props": [{"name": "笔记本", "price": null}],
  "hs": [
    {"ref": "i0", "x": 0.35, "y": 0.45},
    {"ref": "p0", "x": 0.65, "y": 0.35}
  ]
}
```

- `id`：唯一英文/数字/横线/下划线，推荐 `01`…；用于图片文件名和加购记录。
- `img`：必填，支持 PNG/JPG/WebP/SVG。与全局 `imageAspect` 一致，避免 contain 留白造成热区/放大镜错位。
- `hd`：可选高清图，删除该字段可关闭该项放大镜。普通图若抠图或裁剪，高清图也要保持相同画布与主体位置。
- `hidden`：可选，true 时先显示剪影，首次点开拆盒解锁。支持多项独立解锁。
- `items`/`props`：单品/道具数组。`price` 是数字或 `null`；`null` 显示“非卖品”并不参与合计，也没有单品 ADD。未给价格不要填 0 充当未知售价。
- `short`、`cat`：底部短名、小票分类，省略时分别使用 name / ITEM。
- `hs`：热区数组，允许为空。`i0` 指 items[0]，`p0` 指 props[0]。x 从左向右、y 从上向下，范围 0–1；指向的条目必须存在。

小票总额 = 单品与有价道具合计 − 四舍五入后的折扣金额。整套加购计数 +1，不代表单品件数。

## 轮廓遮罩（可选）

`masks` 为按 look id 索引的 48×72 行优先字符串，每格 1 表示主体、0 表示背景。原版示例自带预计算遮罩，独立拷贝普通图、高清图时不要误配其他轮廓。

一般新项目不需要填写：HTTP 下浏览器会从展示图 alpha 自动生成。对于不透明背景图，默认矩形范围内均可显示放大镜。若要求只在不透明照片中的人物上出现，需要先准备透明展示图或提供正确轮廓，不把背景颜色阈值当成可靠抠图。

## 常见问题

- 每个人背后有背景方块：统一照片背景，或准备透明 PNG；修改网页背景不能解决多张照片灰度不同。
- 放大镜内容偏移：先检查普通图和高清图是否裁剪不同、比例不同、主体位置不同，不靠改热区坐标修放大镜。
- 新素材放大镜不出现：删除复制的旧 `masks`，检查 hd 是否存在和鼠标是否压在热区标签上。
- 修改 config.json 后网页没变：运行时加载 config.js；编辑 config.js 或从更新的 JSON 重新生成到新目录。
